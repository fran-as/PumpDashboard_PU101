# 🛠️ Pump Performance Dashboard – PU101 (Mantoverde)

Interactive dashboard for monitoring and analyzing slurry pump performance, integrating hydraulic fundamentals with operational data and condition monitoring.

---

## 📌 Overview

This project consists of a **Streamlit-based dashboard** developed to evaluate the performance of a slurry pump (PU101 – Mantoverde), enabling engineers to visualize, analyze, and interpret pump behavior under real operating conditions.

The tool bridges the gap between **pump engineering principles** and **data analytics**, supporting better operational and maintenance decisions.

---

## 🎯 Key Features

* 📊 **Real-time data visualization**

  * Flow, head, power, efficiency
  * Trend analysis of operational variables

* ⚙️ **Operating point analysis**

  * Comparison against pump curve
  * Identification of operation relative to **Best Efficiency Point (BEP)**

* 🚨 **Performance monitoring**

  * Detection of abnormal conditions
  * Identification of performance deviations

* 🧠 **Decision support**

  * Data-driven insights for operation and maintenance
  * Early identification of inefficiencies and potential failures

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/fran-as/PumpDashboard_PU101.git
cd PumpDashboard_PU101
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
